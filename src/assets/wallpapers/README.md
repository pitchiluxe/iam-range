# Cybersecurity wallpapers

Original artwork generated with the built-in image-generation tool for IAM Range.
Each image is 1672 × 941, stored as a WebP for offline desktop and lock-screen use.

- `blue-shield.webp`: Blue Glass Shield.
- `network-constellation.webp`: Network Constellation.
- `emerald-core.webp`: Emerald Secure Core.

## Generation prompts

Each prompt used this introduction: "Create one finished widescreen 16:9 desktop wallpaper, ideally 2560x1440."

Blue Glass Shield: "A sculptural translucent blue glass security shield nestled among elegant flowing satin-like blue glass ribbons, premium Windows desktop aesthetic, cobalt, ice blue and navy."

Network Constellation: "A beautifully precise abstract cybersecurity network constellation, tiny cyan nodes and delicate luminous interconnecting arcs on deep navy graphite, main sweeping orbital composition toward the right, tasteful restrained premium workstation aesthetic, no dashboards."

Emerald Secure Core: "An elegant sculptural emerald green microcircuit landscape with delicate luminous teal traces converging toward a floating crystalline secure core at the right, dark graphite and emerald, premium minimal Windows workstation aesthetic."

Each prompt ended with: "Original high quality 3D digital artwork with subtle depth, polished lighting, soft atmospheric gradients. Keep the left 40% very dark and quiet for readable desktop icons; focal artwork in center-right. No text, lettering, logos, watermarks, UI, skulls, hackers, padlock clip art, mockup or borders. Entire frame is the wallpaper image."
